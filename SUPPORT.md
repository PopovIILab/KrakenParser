# Support

## Asking questions

If you have a question about installing or using KrakenParser, please open a
[GitHub Issue](https://github.com/PopovIILab/KrakenParser/issues) with the `question` label.

## Reporting bugs

Found a bug? Please open a [GitHub Issue](https://github.com/PopovIILab/KrakenParser/issues)
and include:

- Your OS and Python version
- The exact command you ran
- The full error output
- A minimal example that reproduces the problem, if possible

## Requesting features

Feature requests are also tracked as
[GitHub Issues](https://github.com/PopovIILab/KrakenParser/issues) — please describe the use
case you're trying to solve, not just the feature itself.

## Contributing

See [CONTRIBUTING.md](CONTRIBUTING.md) for how to set up a development environment, run the
test suite, and submit a pull request.
